# 📊 Dynamic Enterprise QA Analytics Dashboard (Next.js + Prisma)

A full-stack, data-driven dashboard application designed to map automation runtimes, system latency parameters, and live telemetry data using a relational PostgreSQL data layer.

## 🚀 Architectural Features
* **Modern Server Components:** Built using Next.js App Router for server-side optimization.
* **Type-Safe Data Layer:** Orchestrated via Prisma ORM connected to a PostgreSQL schema engine.
* **Responsive Visuals:** Designed with Tailwind CSS using a customized developer dark-mode palette.

## 🛠️ Tech Stack
* **Frontend Framework:** Next.js (React)
* **Language Core:** TypeScript
* **Database Management:** Prisma ORM / PostgreSQL
* **Style Engine:** Tailwind CSS

## 💻 Local Workspace Startup

```bash
# 1. Install project packages
npm install

# 2. Boot up the local runtime environment
npm run dev
```
